## Quick Start

```bash
git clone https://github.com/ZeeshanKolachi/neon-snake.git
start index.html   # No install, no build — just open in browser
```

## Features

- 🌌 Space Galaxy theme — starfield, nebula, planet food, comet snake
- ⚡ 4 Power-ups: Speed Boost · Slow Motion · 2× Score · Wall Shield
- 📐 Math Challenge Mode — arithmetic drill through gameplay
- 🏆 Top-10 leaderboard (localStorage)
- 🎵 Procedural ambient music (Web Audio API, no audio files)
- 📱 Mobile support (D-pad + swipe)
- 3 difficulty levels with score multipliers
